# 2D Top-Down Shooter Game

A 2D game written in C++ with SFML, focused on gameplay systems and custom visual effects.  
Every feature and VFX element was implemented from scratch, with textures created in Blender.

## ✨ Features

- Automated map generation with 9 differently sized tiles placed from coordinate rules
- Collision boundaries generated from a black-and-white image map
- Basic leveling and upgrading system (health, stamina, inventory slots)
- 3 unique weapons, each with its own ability and upgraded variant
- Performance optimizations: tile-based animation updates and a low-quality mode
- Saving/loading system with a save file under 100 bytes

## 🛠 Tech Stack

- C++
- SFML
- Blender
